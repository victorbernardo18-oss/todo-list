# To-Do List

Aplicação de lista de tarefas desenvolvida com JavaScript puro.

## Funcionalidades

- Adicionar tarefas
- Remover tarefas
- Marcar como concluída
- Persistência com localStorage
- Contador de tarefas

## Tecnologias

- HTML
- CSS
- JavaScript

## Objetivo

Projeto criado para prática de DOM, lógica e manipulação de estado.
