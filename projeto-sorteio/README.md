# Projeto Sorteio

Aplicacao simples de sorteio de numeros criada com **HTML, CSS e JavaScript**, permitindo gerar um valor aleatorio entre um numero minimo e um numero maximo.

## Visao Geral

Este projeto foi desenvolvido para praticar entrada de dados, manipulacao do DOM e logica com numeros aleatorios usando JavaScript puro.

## Funcionalidades

- Informar valor minimo
- Informar valor maximo
- Gerar numero aleatorio entre os dois valores
- Exibir o resultado imediatamente na tela por alerta

## Tecnologias

- HTML5
- CSS3
- JavaScript

## Como Executar

1. Clone este repositorio:

```bash
git clone https://github.com/victorbernardo18-oss/PROJETOSORTEIO.git
```

2. Entre na pasta do projeto:

```bash
cd PROJETOSORTEIO
```

3. Abra o arquivo `index.html` no navegador.

## Aprendizados Praticados

- Captura de valores com `querySelector`
- Conversao de numeros com `Math.ceil` e `Math.floor`
- Uso de `Math.random()` para sorteio
- Integracao entre HTML, CSS e JavaScript
